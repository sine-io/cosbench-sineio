# #20 Migrated Performance and Resource Profile

This report records three measured runs of the same Java 21 Driver candidate under a Docker CPU/memory/PID limit. It uses one Mock read worker, 25,000 operations per run, 64-byte objects, and one warmup run. A full GC is requested between runs, before each measured window, to reduce carry-over from prior mission allocations. The profile records the reset in each CSV row; GC time is outside measured elapsed time. Legacy performance results and thresholds are historical only and are not used for a regression verdict.

Replay from the repository root with `sudo docker run --rm --cpus=2 --memory=2g --pids-limit=512 --volume "$PWD:/workspace" --volume /home/ubuntu/.m2/repository:/root/.m2/repository --volume "$PWD/shadow/evidence/2026-11-06/performance-profile:/reports" --workdir /workspace --env COSBENCH_PERFORMANCE_REPORT_DIR=/reports --entrypoint /bin/bash maven@sha256:d2230484f42a845db4a2ae5c4b4b2ba474636bc9c17233917f95ddf2110ab06d /workspace/shadow/harness/performance-profile.sh`. The script generates ephemeral test TLS material, removes it at exit, and writes raw mission/request responses, per-run metrics, resource samples, process logs, and container/runtime details to this directory. It replaces only report files owned by this profile.

The profile launches the real Driver application entry point from Maven's test classpath with an isolated test-only Mock provider that records its first operation. It records Driver CPU, heap, threads, file descriptors, RSS, garbage collection, mission counts, latency buckets, throughput, and startup/first-operation/stop timing. Controller process metrics and a production image are not part of this Driver-only profile; the Provider HTTP pool is not applicable to the Mock provider. Ticket #21 owns the production image measurement.

The completed run recorded 25,000/25,000 successful samples and 1,600,000 bytes in each measured trial. Published throughput was 47,438.33, 51,546.39, and 49,212.60 ops/s (mean 49,399.11; population coefficient of variation 3.41%; range/mean 8.32%). Each trial reported p50/p95/p99 in the `0~10 ms` histogram bucket, zero errors, and 100% success. The profile reports these values and their spread without classifying them against an old-version threshold.
